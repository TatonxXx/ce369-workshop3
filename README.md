ข้อ 1 — ex1-callback.js
ข้อนี้ผมเริ่มจากสร้างข้อมูลนักศึกษาขึ้นมาก่อน โดยมีรหัส ชื่อ สาขา และคะแนน แล้วเอาข้อมูลพวกนี้ใส่ไว้ใน Array เพื่อใช้เป็นฐานข้อมูลจำลอง จากนั้นสร้างฟังก์ชัน fetchStudentById() เอาไว้ค้นหานักศึกษาจากรหัสที่ใส่เข้ามา
ในฟังก์ชันผมใช้ setTimeout() กำหนดเวลาไว้ 300ms เพื่อจำลองว่ากำลังไปดึงข้อมูลจากฐานข้อมูลจริง ๆ แล้วเช็กว่ารหัสที่ใส่เข้ามาถูกต้องไหม ถ้าใส่ผิดรูปแบบหรือหาไม่เจอ ก็ส่ง Error กลับไป แต่ถ้าหาเจอก็ส่งข้อมูลนักศึกษากลับมา
ตอนทดลองผมลอง 3 แบบ คือ ใส่รหัสที่มีอยู่จริง ใส่รหัสที่ไม่มี และใส่รหัสเป็นตัวเลข เพื่อดูว่าแต่ละกรณีจะแสดงผลยังไง โดยใช้รูปแบบ (error, student) ถ้ามี Error ก็ให้แสดง Error แล้วหยุด ถ้าไม่มี Error ก็เอาข้อมูลนักศึกษาไปแสดง

ข้อ 2 — ex2-promise.js
ข้อนี้ผมเอาวิธีจากข้อ 1 มาปรับให้ใช้ Promise แทน Callback โดยสร้าง fetchStudentByIdAsync() ขึ้นมา แล้วใช้ new Promise() ในการจัดการข้อมูล
ถ้าหาข้อมูลไม่เจอหรือรหัสผิด ก็ใช้ reject() เพื่อบอกว่าทำงานไม่สำเร็จ แต่ถ้าหาข้อมูลเจอก็ใช้ resolve() ส่งข้อมูลกลับมา ส่วน setTimeout() ก็ยังใช้ 300ms เหมือนเดิม เพื่อให้เหมือนกับการดึงข้อมูลจากฐานข้อมูล
หลังจากนั้นผมลองต่อคำสั่งด้วย .then() โดยขั้นแรกเอาข้อมูลนักศึกษามาแปลงเป็นชื่อกับเกรด ขั้นต่อมาเอาไปทำเป็นข้อความ แล้วขั้นสุดท้ายก็แสดงข้อความออกทาง Console ถ้าเกิดปัญหาจะไปทำงานที่ .catch() ส่วน .finally() จะทำงานตอนจบไม่ว่าจะสำเร็จหรือไม่
ส่วน promisify() เป็นการลองเอาฟังก์ชันที่เป็น Callback มาเปลี่ยนให้ใช้ Promise ได้ ทำให้สามารถใช้ .then() และ .catch() กับฟังก์ชันนั้นได้

ข้อ 3 — ex3-async-await.js
ข้อนี้ผมเอา Promise จากข้อ 2 มาใช้กับ async/await ซึ่งทำให้โค้ดดูง่ายขึ้น โดยฟังก์ชันที่มี await จะต้องใส่ async ไว้ข้างหน้า
ส่วนแรกผมทำ reportSequential() เป็นการดึงข้อมูลนักศึกษาทีละคน โดยใช้ for...of แล้วใส่ await ทำให้ต้องรอคนแรกเสร็จก่อนถึงจะไปคนต่อไป แต่ละคนใช้เวลาประมาณ 300ms ดังนั้น 3 คนก็ใช้เวลาประมาณ 900ms
ส่วน reportParallel() ผมใช้ Promise.all() เพื่อให้ดึงข้อมูลทั้ง 3 คนพร้อมกัน ไม่ต้องรอทีละคน ทำให้เวลารวมเหลือประมาณ 300ms เลยได้เห็นความแตกต่างระหว่างการทำทีละงานกับการทำหลายงานพร้อมกัน
สุดท้ายคือ safeReport() ผมใช้ try-catch-finally เพื่อจัดการ Error ถ้าหาข้อมูลเจอก็แสดงข้อมูล ถ้าหาไม่เจอก็แสดง Error และไม่ว่าจะเกิดอะไรขึ้น finally ก็จะทำงานตอนจบ

ข้อ 4 — ex4-combinators.js
ข้อนี้ผมลองใช้ Promise 4 แบบ คือ all, allSettled, any และ race โดยสร้างฟังก์ชัน wait() ขึ้นมาเพื่อจำลองงานที่ใช้เวลาไม่เท่ากัน และบางงานก็สามารถกำหนดให้ล้มเหลวได้
Promise.all() ใช้ตอนที่ผมต้องการผลลัพธ์ให้ครบทุกงาน ถ้ามีงานใดงานหนึ่งพังก็จะเข้า catch ส่วน Promise.allSettled() จะรอทุกงานจนจบ แล้วบอกว่าตัวไหนสำเร็จหรือตัวไหนล้มเหลว ถึงบางตัวจะพังก็ยังเห็นผลของตัวอื่นได้
Promise.any() ผมใช้ตอนที่ต้องการแค่ตัวแรกที่ทำสำเร็จ เช่น มี Server สองตัว ถ้าตัวแรกพังแต่ตัวที่สองทำงานได้ ก็ยังเอาข้อมูลของตัวที่สองมาใช้ได้ ส่วน Promise.race() จะดูว่าใครเสร็จก่อนก็เอาผลของคนนั้น เช่น ฐานข้อมูลใช้เวลา 1200ms แต่ Timeout ตั้งไว้ 800ms ก็จะเจอ Timeout ก่อน
